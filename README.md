# Лабораторная работа 7. Функции и автоматические проверки

Выполнил: Вариант 1 (Больше порога)

## Описание программ

- `functions.py` - модуль, содержащий чистые функции для вычисления суммы цифр числа, нахождения среднего значения списка, нормализации текста и фильтрации элементов по варианту.
- `main.py` - исполняемый скрипт, взаимодействующий с пользователем и вызывающий функции из модуля `functions.py`.
- `test_functions.py` - набор автоматических проверок (`assert`) для тестирования корректности работы функций.

## Команды запуска

- Запуск основной программы:

  python main.py
